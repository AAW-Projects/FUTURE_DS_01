# 📊 Data Science & Analytics Projects | Future Interns

This repository contains the projects completed as part of the **Future Interns – Data Science & Analytics Internship**. Each project focuses on solving a real-world business problem using **Microsoft Excel** and **Microsoft Power BI** through data cleaning, DAX calculations, interactive dashboards, and business insights.

---

## 📁 Projects Included

### 📈 Task 1 – Online Retail Sales Performance Dashboard

**Objective**

Analyze online retail sales data to monitor sales performance, identify top-performing products and customers, and generate actionable business insights.

**Key Features**

- Data Cleaning using Microsoft Excel
- DAX Measures
- Interactive KPI Cards
- Monthly Sales Trend Analysis
- Country-wise Sales Analysis
- Top 10 Products by Revenue
- Top Customers Analysis
- Interactive Slicers

**Tools Used**

- Microsoft Excel
- Microsoft Power BI

---

### 👥 Task 2 – Customer Churn Analysis Dashboard

**Objective**

Analyze customer churn patterns to understand the factors influencing customer retention and support data-driven retention strategies.

**Key Features**

- Customer Churn KPIs
- Contract-wise Churn Analysis
- Internet Service Analysis
- Payment Method Analysis
- Customer Demographics
- Interactive Dashboard
- Business Insights & Recommendations

**Tools Used**

- Microsoft Excel
- Microsoft Power BI

---

### 💄 Task 3 – Marketing Campaign Performance Dashboard

**Objective**

Analyze marketing campaign performance by evaluating campaign revenue, engagement, ROI, conversions, and customer segments through an interactive dashboard.

**Key Features**

- Campaign Performance KPIs
- Revenue Analysis
- ROI Analysis
- Customer Segment Analysis
- Revenue Trend
- Top Performing Campaigns
- Interactive Filters

**Tools Used**

- Microsoft Excel
- Microsoft Power BI
