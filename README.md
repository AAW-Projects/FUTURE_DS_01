# 📊 Online Retail Sales Performance Analysis

## 📌 Project Overview

This project analyzes an online retail sales dataset using **Microsoft Excel** and **Power BI**. The objective was to clean raw sales data, build interactive dashboards, and generate business insights to support data-driven decision-making.

The project includes two interactive dashboards:
- Executive Sales Dashboard
- Customer Analysis Dashboard

---

## 🎯 Objectives

- Clean and prepare the sales dataset.
- Analyze overall sales performance.
- Identify monthly sales trends.
- Find top-selling products.
- Analyze country-wise sales.
- Identify high-value customers.
- Build an interactive Power BI dashboard.

---

## 🛠️ Tools Used

- Microsoft Excel
- Power BI Desktop
- DAX (Data Analysis Expressions)

---

## 📂 Dataset

**Dataset:** Online Retail Dataset

The dataset contains online retail transactions including:

- Invoice Number
- Product Description
- Quantity
- Unit Price
- Invoice Date
- Customer ID
- Country

---

## 🧹 Data Cleaning

The following data cleaning steps were performed in Microsoft Excel:

- Removed **5,268 duplicate records**
- Removed **9,251 cancelled orders**
- Removed **1,336 records with negative quantities**
- Removed **1,176 zero-priced transactions**
- Verified missing values
- Retained valid transactions with missing Customer IDs

Final cleaned dataset:

**524,879 records**

---

## 📈 Key Business Insights

- United Kingdom generated the highest sales.
- Sales peaked during **November**, indicating seasonal demand.
- A small number of products contributed a significant share of revenue.
- High-value customers generated a large portion of total sales.
- Average revenue per customer was approximately **2.45K**.

---

## 💡 Business Recommendations

- Increase inventory before the peak sales season.
- Strengthen customer loyalty programs.
- Expand marketing outside the United Kingdom.
- Focus on promoting top-selling products.
- Improve inventory planning using seasonal trends.
